# Search documentation

Type a natural-language question the same way you would after the in-editor `help` command. Results are ranked with TF-IDF in your browser — no AI, no server.

The editor can open this page directly with a query string:

```text
/search?q=how+do+I+create+a+new+user+plugin
```
